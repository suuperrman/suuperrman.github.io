Python基础学习笔记

一、初识Python

1.Python介绍

Python是一种高级、解释型、通用编程语言，由荷兰程序员Guido van Rossum于1991年首次发布。Python的设计哲学强调代码的可读性和简洁的语法，使用缩进（空格）来定义代码块。

Python特点：

  • 语法简洁：接近自然语言，学习曲线平缓
  • 解释执行：无需编译，逐行解释运行
  • 跨平台：Windows、macOS、Linux均可运行
  • 丰富的库：标准库+第三方库生态极其丰富
  • 应用广泛：Web开发、数据分析、人工智能、自动化、爬虫等

使用场景：

  • 数据分析与科学计算（NumPy、Pandas）
  • 人工智能与机器学习（TensorFlow、PyTorch）
  • Web后端开发（Django、Flask）
  • 自动化运维与脚本
  • 网络爬虫
  • 游戏开发

五、条件判断

1.单分支

单分支只有一个判断条件，条件成立时执行代码，不成立则跳过。

注意事项：Python使用缩进（通常是4个空格）来表示代码块，而不是大括号。同一代码块的语句必须缩进相同。

2.双分支

双分支有两个分支，条件成立执行一个分支，不成立执行另一个分支。

3.多分支

多分支有多个判断条件，依次检查，满足哪个条件就执行哪个分支。

注意事项：多分支中，只有第一个满足条件的分支会被执行，即使后面的条件也满足。条件顺序很重要，应该把更严格的条件放在前面。

4.嵌套选择

if语句内部还可以嵌套if语句，形成多层判断。

注意事项：嵌套层数不宜过深（建议不超过3层），否则可读性差。可以通过提前返回、合并条件等方式减少嵌套。

5.match

match-case是Python 3.10引入的模式匹配语法，可以替代复杂的多分支if-elif。

match vs if-elif 对比说明：

维度 if-elif match-case
版本 所有版本 Python 3.10+
适用场景 任意条件判断 模式匹配、多值判断
结构匹配 不支持 支持（列表、元组、字典）
可读性 一般 更好（值判断时）

九、函数

1.基本概念

函数是一段可重复使用的代码块，用于完成特定任务。函数可以接收参数，返回结果。

函数的作用：

  • 代码复用：避免重复编写相同的代码
  • 结构清晰：将复杂程序分解为多个模块
  • 便于维护：修改一处，所有调用处生效
  • 抽象封装：调用者只需知道如何使用，不需了解内部实现

2.默认参数

函数的参数可以设置默认值，调用时如果不传该参数就使用默认值。

注意事项：默认参数不要使用可变对象（如列表、字典），否则会出现意外行为。

3.可变参数

可变参数允许函数接收任意数量的参数。

*args vs **kwargs 对比说明：

语法 参数形式 内部类型 含义
*args 位置参数 tuple arguments（任意数量位置参数）
**kwargs 关键字参数 dict keyword arguments（任意数量关键字参数）

4.变量作用域

变量作用域是指变量的可访问范围。Python中有局部变量和全局变量。

作用域查找顺序（LEGB规则）：

  1. Local（局部）：函数内部
  2. Enclosing（嵌套）：外层函数
  3. Global（全局）：模块级别
  4. Built-in（内置）：Python内置

5.匿名函数

匿名函数（lambda）是一种简洁的函数定义方式，只能包含一个表达式。

注意事项：

  • lambda只能包含一个表达式，不能有多条语句
  • lambda适合简单的、一次性使用的函数
  • 复杂逻辑建议使用def定义的普通函数，可读性更好

6.内置函数

Python提供了丰富的内置函数，无需导入即可使用。

7.递归函数

递归函数是指在函数内部调用自身的函数。递归需要有终止条件，否则会无限递归导致栈溢出。

递归三要素：

  1. 基线条件（终止条件）：什么情况下直接返回，不再递归
  2. 递归条件：什么情况下调用自身
  3. 向基线靠近：每次递归都要向基线条件靠近

注意事项：

  • 递归深度有限制（Python默认递归深度约1000层）
  • 递归过深会导致RecursionError
  • 递归代码简洁但可能有性能问题（大量重复计算）
  • 能用循环解决的问题尽量用循环，效率更高

8.本章总结

  • 函数用def定义，可以有参数和返回值
  • 默认参数必须放在非默认参数后面，不要使用可变对象作为默认值
  • *args接收任意位置参数（元组），**kwargs接收任意关键字参数（字典）
  • 变量作用域遵循LEGB规则：局部 -> 嵌套 -> 全局 -> 内置
  • lambda匿名函数适合简单逻辑，常与map/filter/sorted搭配
  • 递归函数要有明确的终止条件，避免无限递归

十二、面向对象

1.基本概念

面向对象编程（OOP）是一种编程范式，将程序组织为对象的集合，每个对象包含数据（属性）和操作数据的方法（行为）。

核心概念：

  • 类（Class）：对象的蓝图/模板，定义了一类对象的共同属性和方法
  • 对象（Object）：类的实例，具有类定义的属性和方法
  • 封装：隐藏内部实现，只暴露必要的接口
  • 继承：子类继承父类的属性和方法，实现代码复用
  • 多态：不同对象对同一消息有不同的响应

2.实例属性

实例属性属于每个对象，每个对象的属性值可以不同。

__init__方法：构造方法，在创建对象时自动调用，用于初始化对象的属性。self参数代表对象本身，必须是第一个参数。

3.类属性

类属性属于类本身，所有实例共享同一份。

实例属性 vs 类属性 对比说明：

维度 实例属性 类属性
所属 每个实例 类本身
数量 每个实例一份 所有实例共享一份
访问方式 self.attr 或 obj.attr ClassName.attr
修改方式 self.attr = 值 ClassName.attr = 值
适用场景 每个对象不同的数据 所有对象相同的数据

4.实例方法

实例方法是类中定义的普通方法，第一个参数是 self，通过实例调用。

5.类方法

类方法用 @classmethod 装饰器标记，第一个参数是 cls（代表类本身），通过类名或实例调用。

类方法的使用场景：

  • 访问或修改类属性
  • 工厂方法：创建类的实例
  • 需要类信息但不需要实例数据的方法

6.静态方法

静态方法用 @staticmethod 装饰器标记，不需要 self 或 cls 参数，与普通函数类似，只是放在类里面。

实例方法 vs 类方法 vs 静态方法 对比说明：

7.类的继承

继承是指子类继承父类的属性和方法，实现代码复用。

注意事项：

  • 子类继承父类所有属性和方法
  • 子类可以添加新的属性和方法
  • 子类可以重写（override）父类的方法
  • super() 用于调用父类的方法
  • Python支持多继承（一个类可以继承多个父类）

8.多态

多态是指不同对象对同一消息有不同的响应方式。

多态的好处：

  • 提高代码的可扩展性：新增子类无需修改原有代码
  • 统一调用方式：不同对象有相同的接口，使用更方便
  • 降低耦合：调用者只需知道接口，不需了解具体实现
